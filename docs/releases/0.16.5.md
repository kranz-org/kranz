# Kranz 0.16.5

Kranz 0.16.5 improves duration labels and TUI dialogs. It requires no
configuration migration and keeps runtime protocol 3.

## Clearer durations and dialogs

Uptime uses readable whole units appropriate to its length. TUI timeout,
restart backoff, and action duration labels omit zero units and separate
remaining units with spaces while preserving configured precision.

Quit and runtime-stop confirmation shortcuts align with the dialog content.
Health history and notifications wrap long messages within a bounded dialog
and support keyboard scrolling. See [TUI controls](../reference/controls)
for the available shortcuts.

## Building from source

Building Kranz or installing it with `go install` now requires Go 1.26 or
newer because the updated `golang.org/x/sys` dependency requires that version.
Homebrew, Linux packages, and prebuilt release archives do not require Go.
See [Installation](../guide/installation) for upgrade commands.

## MCP confirmation tokens

Confirmation tokens have no time-based expiry. They are one-shot tokens
bound to the resolved plan, runtime session, and configuration generation.
See [MCP reference](../reference/mcp) for retry behavior when a token or its
plan is no longer valid.
