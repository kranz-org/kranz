# Kranz 0.19.1

Kranz 0.19.1 makes the dependency viewer usable for starting, stopping, and
restarting services from the dashboard.

## Run an operation in the dependency viewer

Press `g` to open the viewer. Use `←` and `→` to select Start, Stop, or
Restart. `Tab` switches between Graph and Steps for the selected operation.
Graph shows service relationships and current states. Steps shows affected
services in readiness waves or sequential order.

Press `Enter` or click the action below the operation selector. The viewer
stays open and reports progress and the result in that row. Restart acts on
active targets. Use Start to launch stopped services. Press `f` to limit the
operation to the selected services.

See the [animated walkthrough](../guide/tui#inspect-dependencies-and-preview-an-operation)
or try the [dependency viewer example](../examples/dependency-viewer).

## Select dependencies and export a run

Mark services with `Space`, then press `Shift+E` to add their direct and
transitive dependencies to the selection. The shortcut only changes service
marks. To stop that exact set, select Stop in the dependency viewer and enable
Selected only with `f` before running it.

`Ctrl+E` opens export of the selected run to a file. See the
[keyboard reference](../reference/controls) for the full set of shortcuts.
