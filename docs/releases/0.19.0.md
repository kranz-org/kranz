# Kranz 0.19.0

Kranz 0.19.0 adds a dependency graph and operation plans to the dashboard.
It also updates the keyboard shortcuts for selecting, restarting, and stopping services.

## Inspect dependencies and preview operations

Press `g` on a service to see its dependencies above it and the services that
rely on it below. Press `d` or `u` to toggle either direction. The graph shows
current service status, observed health checks, and startup conditions such
as waiting for a setup job to exit successfully.

With several services checked, `g` opens the operation plan. Use `Tab` to switch
between the plan and the graph. In the plan, press `s`, `x`, or `r` to review
start, stop, or restart. It shows requested services, dependency links, and the
order of any work. Colors follow the active accent. Press `f` to compare with
acting only on the selected targets.

See the [TUI walkthrough](../guide/tui#inspect-dependencies-and-preview-an-operation)
and try the [dependency viewer example](../examples/dependency-viewer).

## Lifecycle shortcuts

| Key | Action |
| --- | --- |
| `r` | Start the focused service with its dependencies, or restart it with its active dependents. |
| `Shift+R` | Start or restart only the selected targets, or the focused service when there is no selection. |
| `Ctrl+R` | Confirm restart of all active services. |
| `Shift+A` | Select the focused service and its dependencies. Press again when that exact set is selected to clear it. |
| `Ctrl+A` | Confirm stop of all services. |

When starting only selected targets, Kranz starts checked dependencies before
their consumers and skips readiness gates. See the [controls reference](../reference/controls#lifecycle-and-actions).

## Upgrade

See [Installation](../guide/installation) for Homebrew, Linux packages, and
archives. Existing configuration files require no migration. Start a new
background runtime with the updated binary to use selected-only restarts.
