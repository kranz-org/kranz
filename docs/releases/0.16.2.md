# Kranz 0.16.2

Kranz 0.16.2 lets you stop another local runtime from the TUI's runtime list.
It has no configuration migration.

## Stop another runtime without attaching

Press `p`, select a runtime other than the current one, and press `s`.
The confirmation uses the same shutdown-plan layout as the current runtime's
`q` confirmation. It lists managed processes that will stop, detached services
whose stop commands will run, and detached resources that will remain active.
After confirmation, the TUI stays on the current runtime.

The current runtime has no `s` action in this list. Select it with `Enter`
to close the list, or use `q` from its dashboard to review the usual exit,
detach, and close-and-choose actions.

An incompatible runtime cannot be attached. Its row explains this with a
warning, and `s` offers a confirmed recovery stop. That confirmation lists
only processes verified from runtime ownership evidence. Detached resources
may remain active because their shutdown plan cannot be read across the
protocol mismatch.

See [TUI controls](../reference/controls) for all shortcuts.
