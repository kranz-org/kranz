# Kranz 0.17.1

Kranz 0.17.1 makes log selection shortcuts easier to find and improves action
parameter controls. No configuration migration is required; runtime protocol
remains 3.

## Select all or the visible viewport

While selecting log text, press `Shift+A` to select the whole frozen snapshot
or `a` to select only the visible viewport, including partial wrapped lines.
Both shortcuts appear in the clickable selection footer. `Enter` copies the
selection, and `Esc` returns to normal log navigation.

Select all respects the current panel, run and filter. It includes retained
offscreen text, without retrieving evicted history or adding incoming logs.
Snapshot limits remain 1 MiB / 20,000 logical lines; clipboard requests remain
limited to 64 KiB. Oversized requests are refused without truncation. Narrow
the selection or use whole-run export for larger output.

Selection counts no longer assemble the full payload on each redraw. Leaving
selection preserves the position reached by scrolling, and action status
messages stay beside the selection controls without adding a footer row.
See [selection controls](../reference/controls#select-and-copy-log-fragments)
and the [TUI guide](../guide/tui#copy-a-fragment).

## Action parameters

A single click focuses a parameter or option for reading its details. A double
click changes a checkbox, expands choices, selects an option or opens editing.
The parameter indicator stays beside the command name, before status and
duration, so it remains visible in narrow action lists.
