# Kranz 0.18.0

Kranz 0.18.0 lets you bring your preferred log tools into the terminal UI.
Color a live stream, reformat records or open a familiar viewer while keeping
run history close at hand. Existing configurations continue to work; runtime
protocol remains 3.

## Your log tools, your workflow

Connect a command that reads stdin and writes text or ANSI-colored output:

```yaml
ui:
  logs:
    command: tspin --print
    mode: stream
```

Install the selected tool separately. Shell pipelines and custom scripts work
as well. Choose options that disable the tool's own pager and flush live
output. `Ctrl+G` compares processed and original output; the header shows only
the active status. The shortcut is listed in help.

Kranz selects the service/action and all runs or run #N before processing.
Regex filtering, highlighting, match navigation, scrolling, wrapping, pause,
pinning and text selection work on the result. Pinned output has its own
processor and history scope. Source logs, whole-run export, CLI and MCP keep
the original records.

General transformations may remove or expand lines, so their output has no
invented per-line capture metadata. For a processor that changes only styles,
`preserve_lines: true` verifies unchanged text and order and keeps capture
metadata. Errors fall back to the original output with a notification.

Personal `logs` settings apply across projects; service `ui.logs` overrides
personal and project defaults. See [log tool configuration](../guide/logs-and-ports#your-own-log-tools).

## Open a familiar viewer

```yaml
ui:
  logs:
    command: 'less "$$KRANZ_LOG_FILE"'
    mode: terminal
```

Press `Ctrl+G` to give the terminal to the viewer. It receives a private frozen
snapshot of the selected history and regex filter; this mode does not follow
later output. Exit the viewer normally to return to your previous Kranz
context. Use `$$` for shell variables in project YAML and `$` in personal
settings.

## Try it locally

The [log tools playground](../examples/log-tools) needs only standard shell
tools for its default colorizer. Optional profiles exercise real tailspin and
less. It produces synthetic logs, opens no ports and makes no network calls.

## Move through runs together

`Shift+X` switches every service to its latest run, then back to all runs.
Individual `x` selections remain available; actions and pinned histories keep
their own scope. Interactive shells and actions also benefit from the terminal
handoff correction. Shift+Left/Right now reaches numeric action parameters for
steps of ten.

## Upgrade

No configuration migration is required. See [Installation](../guide/installation)
for Homebrew, Linux packages and archives. Building from source requires Go
1.26 or newer. External log tools remain optional.
