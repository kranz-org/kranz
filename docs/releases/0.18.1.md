# Kranz 0.18.1

Kranz 0.18.1 fixes environment updates when restarting services and keeps
dialogs readable across terminal sizes. No configuration migration is
required; runtime protocol remains 3.

## Environment changes take effect on the next start

After editing an external `.env` or `env_files` file, restart the service to
give its next process the updated environment. Service starts, restarts and
action invocations reread these files without a configuration reload. Removed
variables no longer linger in the next process, and inline environment values
keep their priority.

Changes to inline `env`, file paths and `${VAR}` interpolation in configuration
fields still require `Ctrl+L` or `kranz reload` before restarting. See
[environment configuration](../reference/configuration#env-env-files).

Reordering actions in the configuration also no longer restarts their running
service when the configuration is reloaded.

## Dialogs fit the terminal

Dialogs are limited to 120 columns including padding. Long service names,
descriptions and paths wrap within the available width, leaving space at the
sides of narrow terminals. Existing compact dialogs retain their smaller size.

The theme picker stacks its controls when two columns do not fit. Shortcuts
stay with their action labels, and the theme list leaves room for controls
and configuration paths in a 64×24 terminal.

## Upgrade

See [Installation](../guide/installation) for Homebrew, Linux packages and
archives. Building from source requires Go 1.26 or newer.
