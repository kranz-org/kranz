# Kranz 0.17.0

Kranz 0.17.0 adds selection and copying of log fragments and improves TUI
navigation. No configuration migration is required; runtime protocol remains 3.

## Select and copy log fragments

Focus a main or pinned log panel and drag over the text you need. A double
click selects a token, a triple click selects a logical line, and Shift-click
extends a selection. Dragging can start in padding beside or below the output.
For keyboard selection, press `y` and extend the range with `Shift+Up/Down`.

Press `Enter` to copy the selected source text and `Esc` to return to normal
log navigation. Copy preserves the selection for retry. Unicode, tabs, wraps,
filters and incoming output preserve the selected text; generated timestamps
and source labels are excluded from the copied fragment. Other panels keep
updating while the selection uses a bounded frozen snapshot.

Copy uses the terminal's OSC 52 clipboard support. Terminal permissions, SSH
and tmux settings can affect delivery. A Sent notification reports that Kranz
wrote the request, not that the terminal acknowledged it. Selections are
bounded to 1 MiB / 20,000 logical lines, and clipboard requests to 64 KiB;
oversized requests are refused without truncation. Select a smaller fragment
or use the existing whole-run export when needed.

The log footer also offers `[c] Clear`, with the existing confirmation. Leave
selection with `Esc` before clearing logs. See [selection controls](../reference/controls#select-and-copy-log-fragments),
the [TUI guide](../guide/tui#copy-a-fragment), and
[clipboard troubleshooting](../guide/troubleshooting#nothing-pasted-from-the-tui).

## Action parameters and log navigation

Double-click an action row to expand or collapse its parameters, just as with
`Enter`. A single click focuses the row; use `s` to run the action.

Large log histories no longer hang the TUI, and moving focus between panels
preserves the chosen service log run. Selection remains readable on light,
dark and custom canvases; sixteen-color terminals use reverse video.

## Upgrade

See [Installation](../guide/installation) for Homebrew, packages and archive
